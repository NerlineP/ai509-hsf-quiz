# AI509 × HSF Quiz App

Aplikasyon kèz evalyasyon pou atelye Fòmasyon Fòmatè AI509 × Haitian Sports Foundation.

## Stack
Vite + React · Tailwind · Upstash Redis (Vercel KV)

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in your Upstash credentials
3. `npm run dev`

## Deploy
Connect to Vercel, add KV_REST_API_URL, KV_REST_API_TOKEN, and ADMIN_TOKEN env vars, deploy.

## Links
- Quiz: `/#quiz`
- Admin dashboard: `/#dashboard` (PIN protected)
- HSF dashboard: `/#dashboard-hsf` (read-only, shareable)
